# suit-shop
Full-stack a suit shop web application  .

A full-stack e-commerce platform for premium suits and formal wear, offering separate collections for men (Gentlemen) and women (Ladies).

## ✨ Features

- 🔐 **Authentication** - Email/Password login + Google OAuth (NextAuth.js)
- 👔 **Product Management** - Full CRUD operations for admin
- 🛒 **Shopping Cart** - Add/remove items, calculate discounts
- 🌓 **Dark/Light Mode** - Theme toggle with system preference
- 📱 **Responsive Design** - Fully responsive with Tailwind CSS
- 🎬 **Scroll Animations** - Smooth reveal animations with Framer Motion
- 🗄️ **Database** - MySQL with custom authentication system

## 🛠️ Tech Stack

- **Frontend:** Next.js 15 (App Router), React, Tailwind CSS
- **Backend:** Next.js API Routes, Server Actions
- **Database:** MySQL with mysql2 driver
- **Auth:** Custom JWT + NextAuth.js (Google Provider)
- **Animations:** Framer Motion
- **Icons:** React Icons
